# AegisAI – AI Powered Insurance for Gig Workers

## Problem
Gig delivery workers lose income due to disruptions like rain, pollution, traffic, and curfews.

## Solution
AegisAI is an AI-powered parametric insurance platform that automatically compensates workers when disruptions occur.

## Workflow
Worker → AI Risk Engine → Disruption Detection → Auto Claim → Payout

## Key Features
- AI Risk Prediction
- Dynamic Weekly Premium
- Parametric Trigger System
- Automated Payout
- Fraud Detection

## Parametric Triggers
- Rainfall > 80mm
- AQI > 350
- Temperature > 42°C
- Traffic Congestion > 70%

## Weekly Pricing Model
Premium is calculated based on risk score:
Low Risk → ₹20  
Medium Risk → ₹40  
High Risk → ₹60  

## Tech Stack
Frontend: React  
Backend: FastAPI / Node.js  
AI: Python
